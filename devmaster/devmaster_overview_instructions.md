# devmaster_overview.json — Field Reference

## Required Fields
- **name** (string): Display name shown on the dashboard
- **description** (string): One-liner shown under the project name
- **ports.dev** (number[]): Ports this app uses in development — needed for conflict detection

## Recommended Fields
- **status**: One of: active | paused | archived | idea | maintenance | completed
- **priority**: One of: critical | high | medium | low
- **tags** (string[]): Free-form tags for filtering (e.g. ["react", "mobile"])
- **commands** (Record<string, string>): Named scripts (e.g. { "dev": "npm run dev" })
- **architecture.type** (string): Framework identifier (e.g. "nextjs", "express")

## Optional Fields
- **icon** / **color**: Visual customization
- **ports.custom** (Record<string, number>): Named ports (e.g. { "api": 3001 })
- **architecture.entry**: Main entry point file
- **architecture.apiRoutes**: API routes directory
- **architecture.database**: Database technology
- **architecture.stateManagement**: State management approach
- **architecture.styling**: Styling solution
- **architecture.notes**: Free-text architectural notes
- **links** (array): External links — each has `label` and `url`
- **dashboard.pinned** (boolean): Pin project to top
- **dashboard.group** (string): Group label for organizing
- **batFiles** (Record<string, { path, label, description? }>): Windows .bat files for the Tester
- **setup.lastUpdated**: ISO date string
- **setup.autoGenerated**: Whether config was auto-generated
