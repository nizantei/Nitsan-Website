# devmaster_roadmap.json — Field Reference

## Fields
- **vision** (string): High-level project vision statement
- **currentPhase** (string): Should match a milestone title from devmaster_tasks.json

## Usage
Keep it simple — the detailed progress tracking comes from milestones in devmaster_tasks.json.
This file provides the high-level "where are we going" context for the Roadmap tab header.
